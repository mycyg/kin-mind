# 手机伙伴指令与运行时升级

手机共同会话通过 `model_instructions_file` 加载私有伙伴基础指令，通过
`developer_instructions` 延续现有人设。正文留在私有宿主。探索与创作继续使用
各自的操作与结果契约。角色定位不会替代实际模型、权限、切换和交付回执。

`adapters/mobile-runtime-bundle.mjs` 提供准备、验证、激活、状态读取与回退。
手机保留实际 CLI、ACP 及其依赖，宿主适配器与原始第三方包分别保存，不修改桌面
安装。原生兼容检查使用本地合成提供方，覆盖新建、恢复、维护候选接续、压缩恢复、
重启及模型切换。它证明指令传递，不冒充真实模型行为或实际服务档位。

同一份原子索引保存当前和上一版；重复激活不产生新切换。候选失败不会替换正在
工作的版本，损坏文件不会触发全局 CLI 兜底。第一次迁移另存旧运行时及宿主回退
步骤。回退不覆盖上线后新增的聊天、来源和发送记录。

配置声明、文件就绪、原生加载、实际请求采用分别记录。CLI 0.155 的
`instructionSources` 可能为空；基础文件会被规范化，并可能在不同模型的请求中
位于不同字段。检查以捕获的原生请求为准。只有完成的请求、相互一致的原生元数据、
当前宿主会话和正确的基础/人设组合，才能结算生产采用。

内容摘要用于发布文件和指令的完整性边界。普通状态使用版本与事务，语义由模型
结合来源判断。完成修改后验证受影响路径，不重复执行没有变化的测试矩阵。

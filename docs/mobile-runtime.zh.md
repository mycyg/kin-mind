# 手机伴侣指令与运行时升级

手机共同会话通过 `model_instructions_file` 加载伴侣基础指令，通过
`developer_instructions` 延续同一份人格与说话风格。具体人格正文和共同经历留在
私有宿主，公开库保存通用接入机制与合成测试。

基础指令以中文组织日常相处、自己的兴趣与安排、探索和创作。Kin 可以有不同意见
和情绪，也可以结合实际状态与原因决定接受、延期、减少投入或拒绝工作，不使用
固定情绪分数门槛。拒绝沿已有任务和投递记录结清，未做的事不会登记为完成。

## 指令怎样进入原生会话

宿主从当前人格配置生成精简的开发者指令，不整份复制桌面编程流程。
`include_collaboration_mode_instructions=false` 关闭手机内置协作模板的自动注入，
`project_doc_max_bytes=0` 关闭项目文档的自动常驻注入；操作项目时按需读取其约定。
原生工具、技能说明和实际权限继续由 CLI 提供，这些附加层并未全部替换或翻译。

`compact_prompt` 保留当前话题、关系语境、自己的兴趣与决定、明确更正、约定和
未完成事项，继续使用已有恢复检查点。手机模型目录设置
`use_responses_lite=false`，使用标准 Responses 传递基础指令；模型、思考强度与
Fast 偏好保持原选择，实际服务档位以提供方或原生回执为准。

## 候选验证与自动接入

`adapters/mobile-runtime-bundle.mjs` 提供准备、验证、激活、状态读取与回退。
手机保留实际 CLI、ACP 及其依赖，宿主适配器与原始第三方包分别保存。
私有宿主负责人格投影、候选发现和维护调度；安装公共库本身不会接管手机会话，
也不会下载或升级桌面 Codex。

宿主沿已有每日维护流程检查本机已安装的稳定版 Codex，复用候选运行包与激活
指针，不另建周期任务。原生兼容检查使用本地合成提供方，覆盖基础指令替换、
新建与恢复、维护候选接续、压缩恢复、重启、模型切换和一次实际本地工具调用。
它证明原生协议与指令传递；真实模型的表达与工作能力另用少量隔离对话验证。

兼容候选在现有协调器空闲时接入，保留原逻辑会话、消息、任务和完整模型选择。
同一失败候选不反复测试，稳定版或相关适配来源实质变化后再试。上游接口不兼容
时继续用前一版并记录差异，不自动编写补丁，也不退回默认编程身份。需要更新
ACP 时使用来源可核对的完整运行包，通过同一兼容流程。

同一份原子索引保存当前和上一版；重复激活不产生新切换。候选失败不会替换正在
工作的版本，损坏文件不会触发全局 CLI 兜底。第一次迁移另存旧运行时及宿主回退
步骤。回退不覆盖上线后新增的聊天、来源和发送记录。

## 验证与记录

配置声明、文件就绪、原生加载、实际请求采用分别记录。`instructionSources`
可能为空，CLI 也可能去掉基础文件末尾的换行；磁盘字节与请求中的实际正文分别
核对。在标准 Responses 路径上，基础指令通过顶层 `instructions` 传递，开发者
指令通过 developer 输入项传递。验证绑定对应原生会话与回合，独立标题生成等
辅助请求不当作该回合的指令回执。

首次接入验证闲聊、倾诉、亲昵、明确工作和不确定回忆等有限情境；指令后续变化
只重测受影响的情境。隔离通过、服务健康与自然生产表现分别记录。当前主会话的
实际模型、强度、Fast 偏好和实际服务档位也分开记录，未返回的用量与费用保留未知。

内容摘要用于发布文件和指令的完整性边界。普通状态使用版本与事务，语义由模型
结合来源判断。完成修改后验证受影响路径，不重复执行没有变化的测试矩阵。

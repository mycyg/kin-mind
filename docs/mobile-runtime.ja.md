# モバイルのコンパニオン指示とランタイム更新

共有会話は `model_instructions_file` から非公開の基本指示を読み込み、既存の
人格設定は `developer_instructions` で維持します。探索・制作の独立実行器は
それぞれの契約を保持します。人格設定はモデル、権限、送信結果の証明にはなりません。

`adapters/mobile-runtime-bundle.mjs` は準備、検証、有効化、状態確認、ロールバックを
提供します。実際の CLI と ACP 依存関係をモバイル専用ディレクトリに保持し、
デスクトップのインストールは変更しません。ローカルの合成プロバイダーを使い、
開始・再開、保守候補の引き継ぎ、圧縮後の復元、再起動、モデル切り替えを検証します。
これは指示伝達の検証であり、実モデルの回答品質やサービス層の証明ではありません。

検証済み候補だけを有効化し、現在と前のバージョンを一つの原子的な索引に保存します。
最初の移行では旧ランタイムとホストの復帰手順も保持します。復帰時も新しい会話、
出典、配送記録を残します。宣言、準備、読み込み、実リクエストへの適用は別々に
記録し、空の `instructionSources` を捏造しません。ハッシュはファイルと指示の
整合性に限定し、通常の状態はバージョンとトランザクションで管理します。
